# WPF-UG-getting-started-samples

This repository contains getting started samples for the following WPF controls:

* [Gauges](#gauges)

## Gauges

The Gauge controls provide a rich set of data visualization features for dashboard and KPI scenarios.

### Circular Gauge

The Circular Gauge is a user-friendly control that gives greater UI visualization of data with proportions and percentages of different categories.

[Circular Gauge Sample](./GettingStartedCircularGauge)

[View complete circular gauge features on UG](https://help.syncfusion.com/wpf/radial-gauge/getting-started)

### Linear Gauge

The Linear Gauge is used to display numerical values on a linear scale that shows proportions of a total.

[Linear Gauge Sample](./GettingStartedLinearGauge)

[View complete linear gauge features on UG](https://help.syncfusion.com/wpf/linear-gauge/getting-started)

### Digital Gauge

The Digital Gauge is used to display alphanumeric characters in a digital format that shows values in a digital display.

[Digital Gauge Sample](./GettingStartedDigitalGauge)

[View complete digital gauge features on UG](https://help.syncfusion.com/wpf/digital-gauge/getting-started)
